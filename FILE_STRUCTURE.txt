Key Configuration Files
=======================

include/config.h
----------------
- DEVICE_NAME: "ESP32-RF-Bridge"
- AP_NAME: "ESP32-RF-Setup"
- AP_PASSWORD: "12345678"
- MDNS_HOSTNAME: "esp32-rf"
- RF_RECEIVER_PIN: 22
- RF_TRIGGER_DURATION: 2000 (ms)
- MAX_RF_CODES: 10

platformio.ini
--------------
- Board: esp32dev
- Framework: Arduino
- Libraries:
  - WiFiManager
  - PubSubClient
  - ArduinoJson
  - ESPAsyncWebServer
  - AsyncTCP
  - RCSwitch
- Build flags:
  - MQTT_KEEPALIVE=30
  - MQTT_SOCKET_TIMEOUT=30

Web Interface URLs
==================
- Main: http://esp32-rf.local
- RF Manager: http://esp32-rf.local/rf_manager.html
- Admin: http://esp32-rf.local/solaceadmin
- API: http://esp32-rf.local/api/*

API Endpoints
=============
GET  /api/rf/status       - RF receiver status
GET  /api/rf/codes        - All learned RF codes
POST /api/rf/learn        - Start learning mode
POST /api/rf/stop         - Stop learning mode
POST /api/rf/delete       - Delete RF code
GET  /api/wifi            - WiFi information
GET  /api/mqtt            - MQTT status
POST /api/mqtt/rediscover - Force discovery
POST /api/reset           - Reset configuration

MQTT Topics
===========
State: homeassistant/switch/esp32-rf/rf_X/state
Availability: homeassistant/switch/esp32-rf/availability
Discovery: homeassistant/binary_sensor/esp32-rf_rf_X/config

NVS Storage
===========
Namespace: "rf-bridge"
- mqtt_server, mqtt_port, mqtt_user, mqtt_pass, mqtt_hostname
- rf_codes (array of learned codes)
- rf_count (number of codes)
